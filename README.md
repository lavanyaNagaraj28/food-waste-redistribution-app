# Food Waste Redistribution App

The Food Waste Redistribution App is a technology-based solution designed to reduce food wastage by connecting food donors, NGOs, volunteers, and people in need through a centralized platform. The application helps collect surplus food from restaurants, events, households, and organizations and ensures that it reaches the right people safely and efficiently.

The main goal of this project is to minimize food waste and support communities by creating an easy way for users to donate excess food. Food donors can register and provide details about available food, while NGOs and volunteers can view requests, manage collections, and help distribute food to needy individuals.

## Key Features:
- User registration and login system
- Food donation management
- Donor and NGO communication
- Volunteer support for food collection and delivery
- Food request and tracking system
- Admin dashboard for managing users and activities
- Database management for storing donation details

## Objectives:
- Reduce food wastage in society
- Encourage food donation and sharing
- Connect food providers with organizations that need support
- Improve the efficiency of food collection and distribution

## Technologies Used:
- Frontend: HTML, CSS, JavaScript
- Backend: python,Django
- Database: MySQL / SQLite
